CSS بۆ چییە؟

ئەگەر HTML ئێسکەبەندی بێت، CSS جل و بەرگەکەیەتی. بە CSS ڕەنگ، قەبارە، شوێن دیاری دەکەیت.

h1 {
  color: #6C5CE7;
  background: black;
  padding: 20px;
}

تاقی بکەرەوە - ڕەنگەکە بگۆڕە!

لە چەپ کۆدەکە بگۆڕە بۆ red یان green یان blue:

٣ تایبەتمەندی گرنگ:

✅ color - ڕەنگی نووسین
✅ background - ڕەنگی پشتەوە
✅ padding و border-radius - بۆ جوانکاری
